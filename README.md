# Arbitrary Precision Calculator (APC) in C

A console-based Arbitrary Precision Calculator developed using C programming language to perform arithmetic operations on very large numbers beyond the limit of standard data types.

## Features

* Addition of large numbers
* Subtraction of large numbers
* Multiplication of large numbers
* Division of large numbers
* Supports numbers of arbitrary length
* Accurate digit-by-digit computation

## Technologies Used

* C Language
* Data Structures (Linked Lists)
* File Handling (optional)
* String Manipulation
* Modular Programming

## How to Run

1. Compile:
   gcc *.c
2. Run:
   ./a.out
